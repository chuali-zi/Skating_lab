# Skating Lab

面向花样滑冰选手的移动端跳跃编排与失误预案工具。

选手选择会做的单跳与连跳，填写使用偏好，选择比赛或自定义规则，得到可以自由编辑的跳跃编排与失误补救方案。

## 核心流程

1. 选择单跳和连跳，支持高周数带出低周数动作及连跳搜索。
2. 填写优先、必用或禁用项，选择比赛或上传、描述自定义规则。
3. 生成主编排，编辑动作、拖拽排序、移动后半程分界线，并查看 BV。
4. 默认准备最高 BV 连跳未接上的预案，也可选择其他失误情景。
5. 调整并保存主编排与预案，供训练、赛前回看和讨论使用。
