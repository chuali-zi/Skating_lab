## 关键实现约束

- Android 不进行计分、推理、向量化或视频分析，不存云端模型密钥。服务端身份从 Bearer 会话推导，客户端选手 ID 不是授权依据。
- 开发登录只有显式 `dev` profile 加真实 loopback 连接时可用；正式身份接入尚未实现，默认配置失败关闭。
- 核心 SQL 通过 `TenantJdbc` 在短事务中设置本地选手范围并验证归属，连接池不保留跨请求授权状态；云端调用不占数据库事务。
- 个人更正立即影响档案，不等待向量重建。自然语句提取需要精确原文片段，目标与掌握能力分开；同键含糊冲突标记为 disputed，晚到提取标记 candidate。
- 手动纠正创建新来源并清除不再可信的动作键和到期派生值；明确自然更正记录前驱关系，遗忘沿来源/修订链清理。
- 遗忘/撤回先禁止后续使用，再清理来源正文、历史、向量与派生结果。受影响推荐变为 REDACTED，旧工作任务不能通过租约 CAS 恢复它；旧方案去除解释及规则/选择上下文，版本递增并要求明确重新保存后才能继续推荐。
- 版本替换不混用旧规则，删除不改变不可变的内容版本号。处理任务完成必须匹配租约，删除清理独立退避重试。
- 当前没有把原始规则文档自动宣告为完整可执行规则；缺少规则、时点或分值时，计算显示未知并保留可核对的部分结果。

## 当前未完成或未验证

1. **真实云端教练效果**：没有配置生产模型、Embedding 凭据，尚未做真实推理和教练盲评。实际部署目前是关键词检索；pgvector 查询路径已由真实数据库加测试向量验证。
2. **完整规则包与自由规则执行化**：已有通用计算契约和原文处理，没有把所有 ISU/国内赛事条款自动变成正确可执行规则。Android 在没有明确规则快照时显示待核算。
3. **文档视觉与视频理解**：原件上传、文本解析和处理状态已实现，复杂表格/脚注关系、OCR/多模态回读、逐节 Agent 阅读和视频观察尚待接入。已修复媒体容器信息被当成正文的问题：按实际内容识别媒体，保留原件，等待分析，不将容器信息作为动作/能力证据。
4. **完整记忆产品**：当前已有来源、版本、纠错、遗忘和范围；长期阶段复查、完整训练 episode、个人案例语义索引、明确“以后不要记住此类信息”的持久偏好还未完成。
5. **生产部署能力**：正式账号、教练共享授权、云对象存储、备份恢复删除重放、统一监控及无人轮询时的推荐调度尚待实现。当前私有文件存储是可替换的本地适配器。
6. **框架适配**：本轮先交付可测试的真实 HTTP 模型网关，尚未引入 Spring AI 运行依赖；`LanguageModelGateway` 保持替换边界。
7. **设备兼容性**：已接入 Mobile MCP 并在 Android 16 / API 36 专用模拟器中执行实际界面自测，覆盖范围与修复见 [设备测试记录](android-device-testing.md)。实体手机、不同厂商 ROM 和更低 Android 版本尚未覆盖。

## 运行入口

根目录执行 `scripts/init-local.ps1` 初始化私有本地配置和数据库，再执行 `scripts/start-server.ps1` 构建并启动服务。Android 安装与 `adb reverse` 见 [Android 开发说明](android-development.md)，API 与模型环境变量见 [服务端说明](../server/README.md)。

知识来源调研与导入命令见[专业知识来源记录](knowledge-sources-2026-11-14.md)。开发会话令牌、本地数据库密码、原件、SDK、构建缓存和 APK 均不入 Git；标准构建 wrapper 随代码保存。
